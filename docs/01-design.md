# Phase 1. 아이디어와 디자인

모임 전에 읽고 대화 소재를 챙기는 짧은 브리핑 서비스다. 서비스명은 ‘인싸인척’으로 정한다.

- 핵심 가설: 짧은 배경 설명과 질문 예시가 대화 시작에 도움이 된다.
- 대상: 연령·관심사 구분 없이 새로운 소재가 필요한 사람.
- 흐름: 주제 탐색 → 요약 읽기 → 한마디 복사 → 저장 → 대화 연습.
- 범위: 로그인 없는 샘플 콘텐츠 6건. 실시간 인기 순위는 제공하지 않는다.
- 제외: AI 생성, 크롤링, 계정, 서버 저장, 실제 이용자 검증.

## 화면 기준

밝은 매거진형 화면을 사용한다. 주제 사진과 짧은 제목으로 내용을 구분한다.

| 항목   | 선택                                           | 이유                             |
| ------ | ---------------------------------------------- | -------------------------------- |
| 색상   | 배경 #F7F8FB, 본문 #172334, 강조 #3158E5       | 가볍고 읽기 쉬운 화면            |
| 보조색 | #EAF0FF, #E4F3EB, #FFF1DC                      | 주제·읽음 상태 구분              |
| 글꼴   | Noto Sans KR Variable, 자체 호스팅             | 한글 가독성, 외부 폰트 요청 제거 |
| 배치   | 상단 탐색, 브리핑 배너, 주제 그리드, 대화 예시 | 읽기와 활용을 같은 화면에서 연결 |
| 모바일 | 단일 열, 줄바꿈 탐색, 화면 안쪽 다이얼로그     | 작은 화면과 키보드 대응          |

개인화 추천 대신 공통 주제를 사용한다. 초기 입력은 줄지만 취향별 정확도는 낮다. 자동 수집 대신 편집 샘플로 상호작용을 먼저 확인한다.

## 수용 기준

- 검색과 분야 필터를 함께 적용한다.
- 3개 주제 브리핑의 진행률을 표시한다.
- 저장·읽음 상태를 새로고침 뒤 복원한다.
- 퀴즈는 답변 이유를 보여준다. 성격이나 인기를 평가하지 않는다.
- 키보드 조작, 빈 결과, 저장 실패, 작은 화면을 확인한다.
