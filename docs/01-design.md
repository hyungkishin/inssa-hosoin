# Phase 1. 아이디어와 디자인

> 이 문서는 밈 입문 에디션의 디자인 기록이다. 상황별 대화 중심의 개선은 [Phase 8](08-conversation.md)을 참고한다.

## 요구 수정 · 2026-10-10

핵심은 ‘대화 요령’보다 ‘남들은 아는 밈을 이해하기’다. 기존 대화 연습은 유지한다. 사용자의 치이카와 예시와 Skrr 참고 자료를 반영했다.

- 흐름: 알아보기 → 반응 → 대화 연습 → 결과 공유.
- 입문: 치이카와·하치와레·우사기 구분.
- 확장: 망곰·농담곰·This is fine, 총 6개.
- 상세: 구분법, 출처, 사용 맥락, 대화 예시.
- 추가: 별명·원어 검색, 밈 지식 퀴즈, 내 반응 저장.
- 수익 가설: 무료 입문 → 주간 업데이트·상황별 연습팩 유료화.

## 화면 기준

밝은 도감형 화면을 사용한다. 캐릭터의 실루엣이 잘리지 않도록 이미지를 배치한다.

| 항목 | 선택 |
| --- | --- |
| 색상 | 배경 #F7F8FB, 본문 #172334, 강조 #3158E5 |
| 글꼴 | Noto Sans KR Variable, 자체 호스팅 |
| 배치 | 입문 배너, 카드, 대화 연습, 퀴즈, 프리미엄 안내 |
| 모바일 | 반응형 카드, 화면 안쪽 native dialog |

## 수용 기준

- 캐릭터를 그림과 특징으로 구분한다.
- 밈의 원본과 편집 예시를 구분한다.
- 대화 연습과 지식 퀴즈를 따로 제공한다.
- 저장·읽음·반응을 새로고침 뒤 복원한다.
- 실제 인기·다른 이용자 반응 수를 만들지 않는다.
- 출시 예정 기능을 판매 중인 기능처럼 표시하지 않는다.
