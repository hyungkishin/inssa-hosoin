# Phase 3. QA

로컬 production 서버에서 핵심 흐름 검증을 통과했다. 외부 배포 검증은 [배포 문서](05-deployment.md)에 기록했다. 실제 사용자 테스트는 수행하지 않았다.

검증일: 2026-10-10. 환경: macOS arm64, Node.js 26.8.1, Chromium.

| 검증                | 실행                       | 결과                              |
| ------------------- | -------------------------- | --------------------------------- |
| TypeScript          | `npm run typecheck`        | exit 0                            |
| Unit test           | `npm test`                 | 7개 통과                          |
| Production build    | `npm run build`            | exit 0                            |
| 브라우저 E2E        | `npm run test:e2e`         | 15개 통과                         |
| 접근성              | E2E의 axe-core 검사        | 검사 범위 내 위반 0건             |
| 화면·이미지·runtime | `node scripts/capture.mjs` | HTTP 200, 오류 응답·pageerror 0건 |

E2E는 `npm start`로 실행한 서버를 재사용했다. 결과는 [e2e-results.json](../artifacts/e2e-results.json)과 [visual-check.json](../artifacts/visual-check.json)에 저장했다.

## 확인 범위

- 검색·분야 필터, 빈 결과 초기화, 안 읽은 소재 필터.
- 저장·해제·새로고침 복원, 손상 JSON, 저장 차단, 다른 탭 반영.
- 브리핑 완료·읽음 복원, 모바일 소재 전환, 두 읽기 진입점.
- 퀴즈 피드백·결과·재시작, 복사 성공·권한 거부·상세 화면 알림.
- Enter·Escape·포커스 복원, 320·390·1440px 가로 넘침.
- WCAG 2 A/AA와 2.1 AA 태그의 자동 검사. 홈·브리핑·퀴즈 답변 화면을 검사했다.

## 발견 항목

| 항목                     | 원인                                 | 수정과 확인                                    |
| ------------------------ | ------------------------------------ | ---------------------------------------------- |
| 토글 클릭 실패           | 장식 요소가 input 클릭을 가로막음    | 장식의 pointer-events 제거, 읽음 필터 E2E 통과 |
| 보조 문구 대비 부족      | 밝은 회색·파란색 본문                | 보조색 조정, axe-core 검사 통과                |
| 소재 전환 시 스크롤 유지 | 같은 dialog 안에서 내용만 교체       | 상단 이동·제목 포커스, 모바일 E2E 통과         |
| 상세 복사 알림 접근 불가 | native dialog 밖의 알림은 inert 상태 | dialog 안에 알림 배치, 복사 E2E 통과           |
| 하단 읽기 문구 무반응    | 버튼처럼 보이는 span                 | 실제 button으로 교체, 진입 E2E 통과            |

## 화면 증거와 한계

[데스크톱](../artifacts/desktop.png), [모바일](../artifacts/mobile.png), [브리핑](../artifacts/briefing.png), [대화 연습](../artifacts/practice.png)을 직접 확인했다. 이미지 누락과 가로 넘침은 관찰되지 않았다.

Chromium 자동 검사 결과다. Safari·Firefox, 실제 스크린 리더, 저속 네트워크, 실사용 지표는 검증하지 않았다. 자동 접근성 검사 통과가 전체 접근성 인증을 뜻하지 않는다.
