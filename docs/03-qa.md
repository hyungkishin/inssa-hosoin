## 확인 범위

- 검색·분야·별명·원어, 빈 결과 초기화.
- 저장·해제·새로고침 복원·다른 탭 반영.
- 손상 JSON·저장 차단·복사 권한 거부.
- 치이카와 입문 3단계·읽음 복원·스크롤 초기화.
- 대화 연습과 밈 퀴즈의 피드백·결과·재시작.
- 결과 복사 시 점수와 현재 서비스 URL 포함.
- 내 반응의 저장·새로고침 복원·변경.
- 프리미엄의 가안 가격·출시 예정·로컬 관심 표시 안내.
- 키보드 Enter·Escape·포커스 복원.
- 320·390·1440px 가로 넘침, 홈·입문·연습·퀴즈·프리미엄 자동 접근성.

## 한계

Safari·Firefox, 실제 스크린 리더, 저속 네트워크, 실사용자는 검증하지 않았다. 실제 결제·권한 제공·서버 통계는 구현 범위 밖이다. 자동 접근성 검사 결과는 전체 접근성 인증이 아니다.
