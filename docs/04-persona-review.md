# Phase 4. 페르소나 검증 리뷰

MVP의 주요 흐름을 가상 사용자 관점에서 검토했다. 실제 사용자 인터뷰나 사용성 실험 결과는 아니다.

| 페르소나                   | 확인할 일               | 판단 근거                    | 남은 한계                  |
| -------------------------- | ----------------------- | ---------------------------- | -------------------------- |
| 모임 전 시간이 부족한 사람 | 로그인 없이 소재 챙기기 | 브리핑 시작·완료 E2E         | 3분 소요는 추정치          |
| 주제를 처음 접하는 사람    | 요약 뒤 질문 꺼내기     | 기본 설명·질문·복사 안내     | 이해도 실측 없음           |
| 모바일로 다시 읽는 사람    | 저장 후 복원하기        | 새로고침·저장함 E2E          | 기기 간 동기화 없음        |
| 최신성을 확인하는 사람     | 자료 연도·원문 확인     | 상세 출처·샘플 표시          | 실시간 콘텐츠 없음         |
| 키보드를 사용하는 사람     | 다이얼로그 열기·닫기    | Enter·Escape·포커스 복원 E2E | 실제 스크린 리더 검증 없음 |

## 리뷰 기준

사용자가 소재를 고르고, 읽고, 저장하는 흐름을 우선한다. ‘인싸 점수’처럼 사람을 평가하는 표현은 쓰지 않는다. 퀴즈 결과는 추천 답변을 고른 문항 수만 표시한다.

리뷰에서 카드의 읽기 진입점, 모바일 스크롤 위치, 상세 화면의 복사 안내를 점검했다. 재현 절차와 최종 결과는 [QA 문서](03-qa.md)에 기록한다.

## 다음 검증

실제 사용자에게 첫 소재 탐색, 질문 복사, 저장 복원을 요청한다. 완료 여부와 막힌 지점을 기록한다. 대화 시작에 도움이 됐는지는 사용 후 질문으로 확인한다.

콘텐츠 운영자는 최신성·출처 검토 주기를 정해야 한다. 자동 수집이나 개인화는 이 검증 뒤에 검토한다.
