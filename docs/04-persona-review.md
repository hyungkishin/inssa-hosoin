# Phase 4. 페르소나 검증 리뷰

가상 사용자 관점의 검토다. 실제 인터뷰나 사용성 실험 결과가 아니다.

| 관점 | 확인할 일 | 반영 |
| --- | --- | --- |
| 치이카와를 처음 보는 사람 | 세 캐릭터 구분 | 실제 그림·귀 모양·입문 코스 |
| 별명만 들은 사람 | 망곰·먼작귀 검색 | 별명·원어 검색 |
| 아는 척하기 부담스러운 사람 | 모르는 밈에 반응 | 처음 본다고 묻는 대화 연습 |
| 친구와 같이 해보는 사람 | 결과 전달 | 점수·서비스 URL 복사 |
| 유료 이용을 고민하는 사람 | 제공 범위·가격 확인 | 무료/출시 예정 비교·관심 표시 |
| 모바일·키보드 이용자 | 읽기·닫기·복원 | 반응형·native dialog·포커스 복원 |

사람의 인기나 성격에 점수를 매기지 않는다. 퀴즈는 지식 정답 수 또는 추천 답변 수만 표시한다. 가짜 투표 수나 ‘누가 나를 골랐다’는 알림을 만들지 않는다.

실사용 검증: 캐릭터 이름 회상, 대화 연습 완료, 결과 공유 의향을 관찰한다. 프리미엄 구매 의향은 실제 가격 제시 후 확인한다. 로컬 관심 표시는 시장 수요 검증 자료가 아니다.
