# Phase 6. 반응과 수익모델

## 참고와 가설

[Skrr 공식 App Store 소개](https://apps.apple.com/kr/app/skrr/id1670584329)는 친구 앙케이트와 멤버십 힌트를 설명한다. 인기가 높았다는 정량 근거는 이번 작업에서 확인하지 않았다.

참고할 구조: 짧은 선택 → 즉시 반응 → 다시 참여할 이유. 이 서비스에는 밈 반응, 대화 피드백, 퀴즈 결과 공유로 적용한다. 친구 관계나 투표 서버는 구현 범위 밖이다.

## 무료 → 유료

| 구분 | 범위 | 상태 |
| --- | --- | --- |
| 무료 | 입문 6개, 기본 연습, 퀴즈, 저장, 반응 | 이용 가능 |
| 프리미엄 | 주간 밈 업데이트, 상황별 연습팩, 심화 해설 | 출시 예정 |
| 가격 | 월 3,900원 | 가안·사용자 확정 전 |
| 전환 동선 | 프리미엄 구성 → 관심 표시 | 브라우저 로컬 저장 |

실제 결제와 알림 신청은 발생하지 않는다. 관심 정보가 서버에 모이지 않는다. 유료 구독이나 자동 갱신에 동의한 것으로 해석하지 않는다.

## 판매 전 구현

1. 결제 사업자·상품·가격 확정.
2. 로그인과 사용자별 이용 권한.
3. Checkout, 서명 검증 Webhook, 결제 중복 처리.
4. 유료 콘텐츠 제공, 구독 해지·환불 흐름.
5. 구매·권한 복원·해지 E2E와 운영 점검.

## 검증 지표

- 첫 방문 → 입문 완료율.
- 입문 완료 → 대화 연습 완료율.
- 퀴즈 완료 → 결과 복사율.
- 재방문율과 유료 구성 열람율.
- 판매 시작 후 결제 전환율·해지율.

현재 위 지표를 서버에서 수집하지 않는다. 실제 유료 범위를 운영할 수 있는지 먼저 검증한다.
