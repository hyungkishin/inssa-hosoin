# Phase 8. 상황별 대화 개선

상황 선택 → 첫마디 → 상대 답변 → 후속질문 → 내 대화 메모를 구현했다. 실제 대화 효과·재사용·구매 수요는 아직 검증하지 않았다. [검증안](07-product-validation.md)은 별도로 유지한다.

## 디자인

기존 Noto Sans KR와 밝은 배경·파란 강조색을 유지한다. 첫 화면은 선택별 대화 미리보기와 상황 선택으로 구성한다. 캐릭터 도감은 아래에서 참고한다.

- 색상: 배경 `#F7F8FB`, 본문 `#172334`, 강조 `#3158E5`, 피드백 `#E4F3EB`.
- 상황: 친구의 캐릭터 굿즈, 처음 듣는 작품, 뜻을 모르는 짤.
- 답변: 점수 없이 선택별 맥락과 다음 말을 보여준다.
- 도움말: 접어서 제공하며 관련 도감을 연결한다.
- 모바일: 상황 버튼은 세로 배치, 메모 액션은 전체 너비.

캐릭터 암기와 웃음 중심 상황극도 검토했다. 이번 구현은 후속질문과 개인 메모에 집중한다. 웃음·공유만으로 대화 도움을 판단하지 않기 위해서다. 선택지가 제한돼 자유 대화의 폭은 좁다.

## 개발

구현: [대화 데이터](../src/lib/conversations.ts), [대화 화면](../src/components/conversation.tsx), [홈 연결](../src/components/app.tsx).

- 선택별 상대 답변과 다음 선택지를 연결한다.
- 모든 상대 답변은 서비스가 작성한 예시다. 실시간 AI 응답이 아니다.
- 첫마디와 후속질문은 각각 최대 180자로 수정한다.
- 두 문장이 모두 있어야 저장·복사할 수 있다.
- `inssa-conversations-v1`에 상황별 메모를 하나씩 보관한다.
- 같은 상황을 다시 저장하면 해당 메모를 갱신한다.
- 문장이 같으면 사용 기록을 유지하고, 바뀌면 미사용으로 돌린다.
- 사용 상태: 미사용, 도움 됨, 이어가기 어려움, 상황 없음.
- 알 수 없는 상황·잘못된 타입·빈 문장·중복 메모를 복원에서 제외한다.
- 저장 실패 시 성공 안내를 하지 않는다. 복사 실패 시 직접 복사를 안내한다.

기본 3문항 연습은 상황 선택 화면에서 연다. 도감·읽음·반응·지식 퀴즈·프리미엄 가안 안내는 유지한다. 메모와 사용 기록은 서버에 모이지 않으며, 브라우저 데이터를 삭제하면 사라진다.

## QA

2026-10-10, 로컬 production 서버·Chromium에서 확인했다. 전체 실행 결과와 범위는 [QA 문서](03-qa.md)에 기록한다.

신규 E2E는 선택별 분기, 메모 수정·복사·저장·삭제·복원, 저장 차단, 잘못된 데이터, 사용 기록 유지, 키보드 복원, 320px 접근성을 확인한다. [테스트](../tests/e2e/conversation.spec.ts).

화면 직접 검토: [상황 선택](../artifacts/conversation-picker.png), [선택 후 답변](../artifacts/conversation-branch.png), [메모 편집](../artifacts/conversation-memo.png), [저장한 메모](../artifacts/conversation-saved.png). 모바일 안내 문구와 대화 미리보기 사이 간격을 조정했다.

## 페르소나 검토

아래는 가상 사용자 관점의 검토다. 실제 인터뷰 결과가 아니다.

| 관점 | 확인한 흐름 | 남은 한계 |
| --- | --- | --- |
| 처음 본다고 말하기 부담스러움 | 모른다고 묻는 선택·점수 없는 설명 | 실제 관계에서 부담이 줄었는지 미확인 |
| 상대의 취향이 궁금함 | 좋아하는 이유를 받아 묻는 후속질문 | 예시 밖의 자유 답변은 지원하지 않음 |
| 나중에 직접 써보고 싶음 | 내 말투 수정·메모 복원·사용 상태 | 구체적 발화·상대 반응 수집은 없음 |
| 모바일·키보드 이용자 | 세로 배치·단계별 스크롤·닫기 포커스 | 실기기·스크린 리더 미검증 |

## 배포

[공개 서비스](https://inssa-hoso-people.vercel.app)에 Vercel production 배포를 완료했다. CLI `READY`, 공개 URL HTTP 200, 공개 서비스 E2E 28개 통과를 확인했다.

소스 커밋 `b1b30cc`는 GitHub `main`에 push했다. [배포 정보](../artifacts/conversation-deployment.json)와 [공개 E2E 결과](../artifacts/conversation-deployment-e2e-results.json)를 보관한다.

```sh
DEPLOYMENT_URL=https://inssa-hoso-people.vercel.app npx playwright test --config playwright.remote.config.ts
```

스토어용 앱 패키징과 결제는 이번 구현 범위에 포함하지 않는다.
